## AndroidFitnessApp

Native Android fitness and meal tracking app built in **Kotlin**, featuring Firebase integration, timers, and a calendar-based weekly view.

---

## Features
- 📅 **Calendar-based fitness tracking** (meals & exercises)
- 🔐 **Firebase Authentication & Firestore**
- ⏱️ **Timers** for workouts and rest periods
- 📊 **Weekly summary** using RecyclerView
- ☁️ Cloud-synced day data manager (get/set/delete)
- 🎨 Material-themed UI and intuitive navigation

---

## Tech Stack
- **Kotlin (Android Jetpack, ViewBinding)**
- **Firebase Auth + Firestore**
- **RecyclerView / CalendarView**
- **MVVM architecture**
- **Gradle Build System**
